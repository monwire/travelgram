O projeto Travelgram consiste em template fornecido pela Rocketseat, durante o curso "Full-stack".
Trata-se de um modelo de rede social para postagem de imagens de viagens.
Todo o código foi feito utilizando apenas HTML e CSS, bem como assets disponibilizados na plataforma
"Figma".
O site consiste em página única e não foi publicado oficialmente na web.
